Question 2: Shopping Cart Management Using Redux ToolkitScenario
You are developing an e-commerce application where users can add products to their shopping cart, remove products, and update product quantities.
The application has multiple components, such as ProductList, Cart, and Navbar. The cart item count must be updated everywhere whenever a user adds or removes a product.
Requirements:
Use Redux Toolkit for global state management.
Implement actions to add products, remove products, and update quantities.
Display the total number of items in the navbar.
Display the total price in the cart.
Prevent duplicate product entries by updating the quantity of an existing product.
